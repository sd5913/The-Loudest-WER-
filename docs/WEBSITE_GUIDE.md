# Website controls / 网站操作

Home: navigate with the top bar. Pull the cord for Sunset/Night. Click decorative cats to enlarge them, or drag them directly. The computer contains the short guide.

首页：顶部导航；拉绳切换昼夜；猫咪可点击放大、直接拖动；电脑屏幕提供简短引导。

My Pets: upload a photo, adjust palette/detail, add a short recording or audio upload, then save. Photos are pixelated, not AI cut out. Adopt a preset from the cards below.

我的宠物：上传照片、调整像素效果、添加声音并保存；也可领养预设宠物。

Studio: choose a pet and Play together. Drag performers to move them. Click a pet or mixer shortcut to edit it. Use round scene buttons on the stage. Set section length in the rhythm track area. Advanced mode exposes pitch, tone, instruments, melody and chords. Drop or choose an audio file, inspect the status, preview and trim the clip.

工作室：选宠物后播放；直接拖动宠物；点击宠物或调音台快捷按钮编辑；舞台圆形按钮切换场景；音轨区设置长度。声音可上传、试听和裁剪。

Optional backing-song generation follows the sound controls. It requires a locally configured API proxy. The existing AI sample feature takes a text prompt; reference-audio cloning has not been validated.

Save Music opens a naming dialog. My Collection reopens or removes a local song. Copy local link only works with data in this browser; Export WAV creates audio you can send to someone else.

保存后可从收藏重开。本机链接不会上传歌曲，分享声音请导出WAV。
