Six original WAV examples, one short synthesized call per built-in pet. These are playful sound-design effects generated for this prototype; they are not recordings of real animals. Select “Sample call · WAV 示例音效” in the studio, press the note button, or preview/download a sample in Pet Gallery.
cat-meow-call.wav is an original synthesized three-call meow used as Orange Cat's first example voice.
pet-singing-meow.wav is an original synthesized high-pitched melodic meow. Replace this WAV to change the shared Singing Meow option for all pets.
pet-hum-call.wav is a retired prototype asset and is not used by the site.
