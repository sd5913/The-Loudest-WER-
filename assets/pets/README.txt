Replaceable pet artwork

Drop transparent PNG files here using these exact names:
cat.png, dog.png, bird.png, bunny.png, frog.png, fox.png

The artwork is used automatically by the matching pet in the studio, editor and picker. Keep a transparent background and a roughly 96:68 character canvas (for example 384x272 px). The image is displayed with pixelated scaling. If a PNG is missing, the original built-in pixel sprite appears automatically.

Home room character PNGs are `mystery-cat-guitar.png`, `orange-cat-christmas.png`, and `white-cat-christmas.png`. Matching `*-alt.png` files are brief alternate frames shown in the enlarged portrait. These scene sprites are separate from the reusable 96:68 studio pet artwork above.
