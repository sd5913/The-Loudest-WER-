Replaceable music stages / 可替换音乐舞台

Neon Night / 霓虹夜晚: stage-neon-night.png
Sunny Park / 晴天公园: stage-sunny-park.png

Replace either PNG in this folder, keeping the filename and 395 × 223 canvas ratio. Refresh the Music Studio page and select the corresponding scene. The picture includes the central microphone, so keep it in the new artwork.

在此文件夹原位替换任一 PNG，保留文件名及 395 × 223 的画布比例。刷新音乐工作室页面，再选择对应场景。中央麦克风已包含在图片中，新图也请保留。

Add a new shared scene / 添加团队共用的新场景
1. Put a new PNG in this folder. A 395 × 223 canvas works best.
2. Add one entry to stages.js: {id:'garden', name:'Moonlit Garden', zh:'月光花园', file:'stage-garden.png'}
3. Refresh studio.html. The new scene appears in the Scene menu for everyone who has the updated project files.

1. 把新 PNG 放到本文件夹，建议画布为 395 × 223。
2. 在 stages.js 中添加一条，如上方示例；id 不要与已有场景重复。
3. 刷新 studio.html。团队成员拉取更新后的项目文件，即可在 Scene 菜单看到新场景。

The Add Scene button also accepts personal PNG/JPG images on the page. They stay in this browser and are not added to the project files or shared automatically. Use the steps above for team assets.
页面上的 Add Scene 按钮也能上传个人 PNG/JPG，但只保存在当前浏览器，不会自动写入项目文件或同步给团队。团队共用素材请按以上步骤添加。
